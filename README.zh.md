# 加密货币套利实时监控面板

> 中文 · [English](README.md) · [Windows 服务器部署指南](DEPLOY.zh.md)

实时扫描加密货币跨交易所套利机会。覆盖 **Binance / OKX / Bybit / Gate.io /
Bitget** 五家交易所的全部 USDT 现货 / 线性永续 / 交割合约，计算五类套利收益
并通过 WebSocket 推送到自包含的 Web 面板。

## 这个项目解决什么问题

当前加密货币市场上最有空间的套利**不在 BTC/ETH 主流币**——那些价差被做市
商在毫秒级吃掉了。真正还有机会的是**中长尾山寨币的资金费率分化**：同一个
币在不同交易所的 funding rate 可能差到一边收 0.5%/8h，另一边付 0.1%/8h，
合起来是几百到上千的年化。这个面板的目的是把这种机会实时挖出来，按年化
排序展示，并通过流动性过滤剔除假信号。

## 功能

- **5 个套利视图**，每张表都可按任意列排序：
  1. ⭐ **资金费率跨所分化** —— 一所做多 + 另一所做空，双边吃 funding
  2. **单所资金费率** —— 现货 + 永续空单的经典套保
  3. **现货 vs 交割合约基差** —— 按距到期天数年化
  4. **跨所永续价差**
  5. **跨所现货价差**
- 扫描 5 个交易所全部 USDT 交易对（每轮约 6,000 个 ticker）
- **币种归一化**——`1000PEPE` / `kPEPE` / `PEPE` 统一为同一币，跨所可比对
- **流动性 / 质量过滤**——最低 24 小时成交额、bid/ask 自身价差合理性检查，
  避免在死币上看到"5% 假价差"
- **WebSocket 实时推送**，变动的单元格会闪烁
- **中英文切换**，浏览器默认按系统语言，手动切换记忆在 localStorage
- **代理感知** —— 从 `.env` 读 `HTTPS_PROXY`，方便国内用户走本地代理
  （Clash / V2Ray 等）

## 快速开始

```bash
git clone https://github.com/<你的用户名>/crypto-arb.git
cd crypto-arb
pip install -r requirements.txt

# 国内用户配置本地代理：
cp .env.example .env
# 编辑 .env，如果你的代理不在 127.0.0.1:1082 改成对应端口

python3 -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 8765
```

浏览器打开 <http://127.0.0.1:8765>。

首次启动约 10-30 秒（要加载 5 个交易所的全部 market），之后每 8 秒刷新一次。

### 运行环境

- Python 3.10+
- 能访问交易所公网 API 的网络。国内用户需要本地代理，在 `.env` 里设：
  ```
  HTTPS_PROXY=http://127.0.0.1:1082
  HTTP_PROXY=http://127.0.0.1:1082
  ```

## 5 个视图详解

### 1. ⭐ 资金费率跨所分化（核心视图）

同一币在多个交易所都有永续合约时，资金费率经常不一致——尤其山寨币和 meme 币
更明显。比如 A 所多头要付 +0.5%/8h，B 所多头反而能收 0.1%/8h，那就可以：

- 在 **A 所做多**（funding 越负你越赚）
- 在 **B 所做空**（funding 越正你越赚）

两腿对冲掉价格风险，纯吃**两边 funding 合计**的差。

| 列 | 含义 |
| --- | --- |
| 做多所 / 多腿费率 | funding 最负的交易所（你做多收钱） |
| 做空所 / 空腿费率 | funding 最正的交易所（你做空收钱） |
| 间隔h | funding 结算间隔（1/4/8 小时） |
| 8h价差% | 两腿合计，按 8 小时归一化 |
| 年化% | 长腿年化 + 短腿年化 之和 |
| 最小成交$ | 两腿中较小的 24h 成交额，是你实际能上的资金上限 |

> ⚠ 超高年化（>200%）几乎都是单边瞬时极端值，通常 1-2 个 funding 周期就回归。
> 不要按"全年这个收益率"估算资金，看到 1000% 别 all-in。

### 2. 资金费率（单所）

经典 cash-and-carry：在同一交易所拿现货 + 永续做空。你收当期资金费率，
价格波动被对冲掉。

| 列 | 含义 |
| --- | --- |
| 现货 / 永续 | 当前最新成交价 |
| 基差% | (永续 − 现货) / 现货，理论应接近 0 |
| 本期费率 | 当期 funding rate |
| 年化% | funding × (8760 / 间隔小时数) × 100 |

### 3. 期现基差

季度 / 交割合约通常对现货有溢价（contango），做空合约 + 持现货，到期合约
价格收敛回现货。

| 列 | 含义 |
| --- | --- |
| 距到期 | 距结算日的天数 |
| 基差% | (期货 − 现货) / 现货 |
| 年化% | 基差 × 365 / 距到期天数 |

### 4 & 5. 跨所价差

同一币在不同所之间的价差。最便宜的所买入，最贵的所卖出。

> ⚠ **现货**：实际操作时提币时间（几分钟到几小时）+ 链上手续费会吃掉
> 0.3% 以下的价差。面板会显示更小的价差，但只能看着，做不了。
>
> **永续**：不用提币，但要扣两边的吃单手续费，并且要管理爆仓风险。

## 系统架构

```
                ┌────────────────┐
                │  浏览器 (UI)   │  ◄── HTML/CSS/原生 JS，无框架
                └────────┬───────┘
                         │ WebSocket（每 8 秒推送）
                ┌────────▼───────┐
                │   FastAPI app  │  backend/app.py
                ├────────────────┤
                │  轮询循环      │  每 8 秒调用 fetch_all()
                └────────┬───────┘
                         │
                ┌────────▼────────────────────────┐
                │  exchanges.py (ccxt async)      │  5 个交易所
                │  Binance · OKX · Bybit · …      │  并发拉取
                └────────┬────────────────────────┘
                         │
                ┌────────▼───────┐
                │  arbitrage.py  │  过滤器 + 5 类计算
                └────────────────┘
```

单 Python 进程，无数据库。最新一次报告缓存在内存里，广播给所有 WebSocket
客户端。重启会丢缓存，下一轮自动重新拉。

## 过滤器

两层过滤剔除噪声：

1. **后端硬过滤**（`arbitrage.py`）：
   - funding / 跨所视图：24h 成交额 ≥ 100 万 USDT
   - 期现基差视图：24h 成交额 ≥ 10 万 USDT
   - bid/ask 自身价差 ≤ 0.5%（剔除盘口太薄的）
   - 每张表上限 200 行

2. **前端可调过滤**（顶部控件）：
   - 币种关键词搜索
   - 最低 24h 成交额下拉（不限 / 10万 / 100万 / 1000万 / 1亿）

## 常见陷阱

| 现象 | 原因 / 解决 |
| --- | --- |
| 单所资金费率里出现 "529609% 基差" | 不同交易所的同名 ticker 实际上是不同的项目（如 bitget 的 FLY 永续和 FLY 现货是两个币）。看到明显异常值忽略即可。 |
| Bitget / Gate 首次加载为空 | 代理下首次请求偶尔超时，等下一轮即可。 |
| 全部交易所都失败，报 `gateio.ws` 错误 | 代理没生效，检查代理是否运行、`.env` 是否正确。 |
| 资金费率年化 5000%+ | 单期 funding 推算的年化，会回归。不要按这个值估算资金占用。 |
| 跨所现货价差看着很诱人 | 提币费 + 链上时间会吃掉 0.3% 以下的，实操做不到。 |
